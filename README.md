OBIRI Website — Frontend Repository

This repository contains the frontend codebase for the OBIRI ERP Website, a modern landing page designed to communicate OBIRI’s value proposition, modules, pricing, and multi-location business capabilities.

The website is fully responsive, lightweight, and structured for ongoing improvements as OBIRI grows.

📌 Project Overview

OBIRI is a multi-tenant Enterprise Resource Planning (ERP) platform built for SMEs and multi-location businesses across Africa.

This website serves as the public-facing marketing page that introduces visitors to:

OBIRI’s key modules

Multi-location and multi-tenant capabilities

Pricing plans

Testimonials from real users

Frequently asked questions

The overall product mission and value

✨ Key Features
1. Multi-Location & Multi-Tenant Messaging

Explains how OBIRI helps businesses manage multiple branches, outlets, warehouses, or business units from a single central dashboard.

2. Fully Responsive Design

Optimized for desktop, tablet, and mobile devices, including:

Mobile hamburger navigation

Mobile horizontal slider for modules

Stacked layouts for small screens

3. Interactive Modules Section

Tab switching on desktop

Horizontal slider on mobile

Updated module copy with real business scenarios

4. Pricing Toggle

Monthly vs Annual pricing

Featured plan styling

Clean card layout

5. Testimonials Section

Glass-effect testimonial cards

Background glow and imagery

Three-column → single-column responsiveness

6. FAQ Accordion

Click-to-expand interactions

Smooth transitions

Accessible markup

7. Unified Newsletter Forms

Email input in hero section

Email input in footer section

Consistent styling via .email-input class

🚀 Running the Project Locally

Clone the repository:

git clone https://github.com/YOUR-USERNAME/obiriwebsite.git


Navigate into the folder:

cd obiriwebsite


Open index.html in any browser
or run using VS Code’s Live Server extension.
